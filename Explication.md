# Battery State of Charge (SOC) Estimation

## Overview
This project investigates battery State of Charge (SOC) estimation using model-based and data-driven approaches.

## Methods
- Second-order equivalent circuit model (ECM)
- Extended Kalman Filter (EKF)
- Long Short-Term Memory (LSTM) neural network
- Performance comparison between estimation approaches

## Tools
- MATLAB / Simulink

## Objectives
- Model battery electrical behavior using a second-order equivalent circuit.
- Estimate SOC using an Extended Kalman Filter.
- Explore LSTM-based SOC estimation.
- Compare the performance of model-based and data-driven methods.

## Project Structure
The repository contains the implementation files, simulation results, and documentation associated with the SOC estimation study.
